## What it does

`main.ts` writes a single one-line joke about office life (95 characters) to `/output/entry.txt`, where the judge reads it:

> My boss calls it an open-door policy, but the door is open so he can hear when you stop typing.

## Run it

Node 22, standard library only, no dependencies:

```sh
node main.ts
cat /output/entry.txt
```
